# Умный стол - Поиск компонентов

Этот набор файлов поможет вам найти и сравнить все необходимые компоненты для создания умного стола.

## 📁 Структура файлов

### 1. `умный-стол-компоненты.md`
Основной документ с описанием всех компонентов и таблицами для заполнения ссылками на маркетплейсы.

### 2. `рекомендации-по-выбору.md`
Детальные рекомендации по выбору каждого компонента с техническими характеристиками, ценами и советами.

### 3. `search_components.py`
Python скрипт для генерации готовых ссылок для поиска на маркетплейсах.

### 4. `шаблон-для-заполнения.csv`
CSV файл для удобного заполнения найденных товаров. Можно открыть в Excel или Google Sheets.

### 5. `search_links_*.json`
JSON файл со всеми ссылками для поиска (генерируется автоматически при запуске скрипта).

## 🚀 Как использовать

### Шаг 1: Запустите скрипт для генерации ссылок

```bash
python3 search_components.py
```

Это создаст файл `search_links_*.json` со всеми готовыми ссылками для поиска.

### Шаг 2: Используйте ссылки для поиска

Откройте сгенерированные ссылки в браузере и найдите товары на каждом маркетплейсе:
- Алиэкспресс
- Озон
- Яндекс Маркет
- Wildberries
- Другие специализированные сайты (если указаны)

### Шаг 3: Заполните таблицы

Для каждого компонента найдите **10 лучших вариантов** и заполните:

1. **В файле `умный-стол-компоненты.md`** - таблицы в Markdown формате
2. **В файле `шаблон-для-заполнения.csv`** - для удобной работы в Excel

### Шаг 4: Сравните и выберите

При заполнении обращайте внимание на:
- ✅ **Цену** - сравнивайте на разных площадках
- ✅ **Рейтинг** - минимум 4.0+
- ✅ **Количество отзывов** - минимум 10+
- ✅ **Технические характеристики** - соответствие требованиям
- ✅ **Сроки доставки** - особенно для Алиэкспресс
- ✅ **Гарантию** - наличие и условия

## 📋 Компоненты для поиска

1. **Подсветка LED** - лента с экранированием/рассеивателем
2. **USB Hub зарядный** - для подключения устройств
3. **Подстолье регулируемое** - электрическое или механическое
4. **Фанера** - выбор вида древесины для столешницы
5. **Контроллеры питания DC-DC** - для распределения питания
6. **Удлинитель/розетки** - решение для подключения устройств

## 📊 Формат заполнения таблиц

Для каждого товара укажите:
- **Наименование** - полное название товара
- **Ссылки** - прямые ссылки на товар на каждом маркетплейсе
- **Цена** - актуальная цена в рублях
- **Рейтинг** - оценка товара (например, 4.5)
- **Отзывов** - количество отзывов
- **Примечания** - важные детали (гарантия, доставка, особенности)

## ⚠️ Важные моменты

1. **Проверяйте совместимость** - убедитесь, что компоненты работают вместе
2. **Рассчитывайте мощность** - суммируйте потребление всех устройств
3. **Учитывайте доставку** - особенно для Алиэкспресс
4. **Читайте отзывы** - обращайте внимание на негативные отзывы
5. **Сравнивайте цены** - один и тот же товар может сильно отличаться в цене
